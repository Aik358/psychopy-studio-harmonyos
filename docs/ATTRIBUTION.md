# PsychoPy Studio OH — 版权与致谢

## 原始项目

本应用是开源软件 [PsychoPy](https://www.psychopy.org/) 的鸿蒙系统（HarmonyOS）移植版本。

- **原项目名称：** PsychoPy
- **原作者：** Jonathan Peirce 与 [Open Science Tools Ltd](https://opensciencetools.org/)
- **原项目网站：** https://www.psychopy.org/
- **源代码：** https://github.com/psychopy/psychopy
- **原项目许可协议：** [GNU General Public License v3 (GPLv3)](https://www.gnu.org/licenses/gpl-3.0.html)

## 鸿蒙移植

- **移植开发者：** A9iska
- **移植版本：** PsychoPy Studio OH
- **源代码：** https://gitcode.com/A9iska/psychopy-oh
- **基于版本：** PsychoPy 2026.1.2
